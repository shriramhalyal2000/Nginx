This is a simple webserver.

This is served through nginx as webserver on ec2 instance. The nginx.conf file are on /etc/nginx/sites-available/amazon.com, the site enabled through /etc/nginx/sites-enabled/ to serve active http static content. the static web page is at /var/ww/html.

only keep *.conf file at sites-enbabled that you catively want to serve, but can have as many domain *.conf files in /etc/nginx/sites-available/
